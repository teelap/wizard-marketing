The base card: paper fill, 4px ink outline, 20px corners, 10px hard shadow. Everything boxed in the kit is one of these.

- `index` (ruled index card) for newsletters and notes, `legal` (yellow legal pad) for fine print and policies, `sticky` (pink, tilted) for a single aside.
- Never add a coloured left border or rail to a card; colour goes in a top band (`ServiceCard`) or the fill.

```jsx
<Card><Display as="h3" size="sm">The fine print</Display><p>No contracts. Cancel any time.</p></Card>
<Card variant="index">One marketing truth a week.</Card>
```
