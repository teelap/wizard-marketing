One of the six illustrated 70s icons (ink outlines, flat brand colours). Use them for offers and destinations, never as decoration in running text.

- Each icon belongs to one thing: `consulting` (magnifying glass), `mastermind` (speech bubbles), `dominoes` (the book), `podcast` (microphone), `tools` (toolbox), `contact` (envelope). Don't reassign them.
- For small UI glyphs (arrows, socials, menu) use Font Awesome 6 (`<i className="fa-solid fa-arrow-right" />`), not these.
- Never use emoji in their place.

```jsx
<Icon name="consulting" size={88} />
<Icon name="podcast" size={64} alt="Podcast" />
```
