Yellow highlighter box with an ink outline and offset shadow, for the key word in a display heading ("Ways to work together.").

- One per heading, on the last word, full stop included. Set `hasHighlight` on the heading (`Display`, `SectionHead`, `Hero`).
- Don't use it inside body copy; use `Wavy` there.

```jsx
<Display hasHighlight>The brutal <Highlight>truth.</Highlight></Display>
```
