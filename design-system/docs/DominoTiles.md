A grid of domino tiles for a numbered set of ideas (the Eight Dominoes, steps of a method).

- Four per row on desktop. Cycle colours red, sky, mint, pink, yellow, teal, salmon, maroon.

```jsx
<DominoTiles items={[
  { n: '01', color: 'red', title: 'Core Attraction', children: 'The emotion your customer is actually buying.' },
  { n: '02', color: 'sky', title: 'Attention Catalyst', children: 'The hook that earns the first three seconds.' },
]} />
```
