Numbered steps: a coloured number coin beside each step's title and text. Only for things that really happen in order.

```jsx
<Steps items={[
  { title: 'Book the call', text: 'Thirty minutes, $400. Bring the numbers.' },
  { title: 'Find the bottleneck', text: 'We look at what the buyer actually wants.' },
  { title: 'Fix the message', text: 'You leave with the rewrite, not a deck.' },
]} />
```
