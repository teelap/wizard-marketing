# Grimoire content backlog

top unchecked topic in **Queue**, drafts it as `draft: true` via the `grimoire-post`
skill, moves it to **Drafted — awaiting review**, and pings Jake. It never publishes and
never invents data. When the Queue drops to 2 or fewer topics, it stops and asks Jake to
add topics + data instead of guessing.

**To publish a reviewed draft:** flip `draft: true` to `draft: false` (or tell Claude
"publish &lt;slug&gt;"), then build + push.
