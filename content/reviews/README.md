# Reviews — the program's performance history

One file per week (`2026-Wnn-review.md`), written by the **`weekly-review`** skill late each Sunday. Each review is the record of:

1. **What performed** — the week's posts scored by format card / hook / subject / Topic Type / platform / time, normalized within each network.
2. **What changed** — the bounded, evidence-backed tuning auto-applied to the format library (tier moves, emphasis notes, timing), each with its evidence and a git-revert note.
3. **What's recommended** — the bigger calls left for Jake (cadence, platform add/drop, strategy, voice — never auto-applied).
4. **What to try next** — 1–2 experiments for the coming week.

This is the **scoreboard** ([../formats/README.md](../formats/README.md) §6) made durable: the loop that turns researched best-practice into what actually works for *Jake's* audience, compounding week over week. The reviews build on each other — each one reads the last.

> Voice and brand canon (`VOICE_DOSSIER`, `CONTENT_GUIDE`) are **not** tuned here — they're human-owned. The review tunes formats, emphasis, and cadence only.
